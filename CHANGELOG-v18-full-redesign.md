# Day Flow v18 — Complete UI Redesign

## Visual system
- Replaced mixed gold/neon/lavender accents with a coherent Pantone-inspired Cloud Dancer / Faded Denim / lilac / warm mocha palette.
- Unified glass surfaces, borders, shadows, radius, input states, focus rings, progress charts and primary actions.
- Reduced dashboard padding and mobile spacing; made navigation a calmer horizontally scrollable pill row.
- Preserved the time-adaptive starry background, but lowered saturation so content is easier to read.

## Language and content
- Refined the app tagline and several labels for clearer Persian microcopy.
- Standardized task-related wording to «تسک» in the main task flow.
- Renamed visible labels for negative habits and challenges without changing their internal tab IDs.
- Clarified that water target is a suggested daily goal, not a universal medical recommendation.

## Behavior / safety of change
- No task, medication, water, habit, calendar, account, export/import or storage logic intentionally removed.
- Kept existing element IDs and data-tab values to avoid breaking event handlers.
- This is a visual/content redesign, not a claim that new backend features or cloud sync have been implemented.
